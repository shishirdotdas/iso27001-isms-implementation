# ISMS Scope Statement - CloudScale Technologies

## 1. Boundary & Applicability
The scope of the Information Security Management System (ISMS) encompasses all core business processes, infrastructure, and personnel supporting the CloudScale B2B SaaS platform.

* **In-Scope Cloud Infrastructure:** AWS Account ID `123456789012` (us-east-1, us-west-2).
* **In-Scope Services:** User Authentication, SaaS Application APIs, PostgreSQL Database, Customer Support Portal.
* **In-Scope Locations:** Remote workforce operating across North America (virtual boundary).
* **Exclusions:** Legacy on-premise testing server (decommissioned Q3 2026; no production/customer data stored).
